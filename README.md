# AjaSchedule

Agendador desktop para Windows que executa comutações programadas em matrizes de vídeo AJA KUMO 64x64.

## Como executar

```bash
pip install -r requirements.txt
python AjaSchedule.py
```

Na primeira abertura, escolha o idioma e informe o IP da matriz. Configurações, agendamentos e logs ficam
na pasta de execução e não vão para o repositório.

## Testes

```bash
pip install -r requirements-dev.txt
python -m pytest
```

## Marcas

Projeto independente, sem vínculo com a AJA Video Systems. AJA e KUMO são marcas
de seus respectivos proprietários e são citadas apenas para indicar compatibilidade.
